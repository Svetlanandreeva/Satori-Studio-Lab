# Промо-сайт satorilabural.ru

Всё, что видит посетитель сайта, лежит в этой папке. Сборки нет: это обычные HTML, CSS и JS.

| Файл | Что это |
|---|---|
| `index.html` | главная промо-страница (`/`, `/na-zakaz` и любой другой адрес) |
| `raboty.html` | каталог работ (`/raboty`) |
| `style.css` | стили обеих страниц |
| `app.js` | формы, кнопка «Хочу похожий», просмотр фото, цели Метрики |
| `img/hero.jpg` | фото первого экрана |
| `img/works/` | фото работ |
| `img/p/` | фото блока «Как мы работаем» |

## Как править

1. Откройте файл здесь, на GitHub, нажмите карандаш, внесите правку, нажмите **Commit changes** (ветка `main`).
2. Сервер сам забирает изменения из ветки `main` раз в две минуты. Через 1–2 минуты правка на сайте.
3. Если что-то сломалось: откройте историю файла (**History**) и верните прошлую версию — она выкатится так же.

Новое фото: загрузите файл в `img/works/` (кнопка **Add file → Upload files**) и добавьте в нужную страницу блок

```html
<figure data-name="Название работы"><img src="/promo/img/works/ИМЯ_ФАЙЛА.jpg" alt="Название работы — работа SATORI" width="720" height="900" loading="lazy"><button class="like" type="button">Хочу похожий</button></figure>
```

Фото лучше ужимать до 760 px по ширине: страница грузится с телефонов.

## Что нельзя ломать

- Якоря главной стоят в объявлениях Яндекс Директа: `#lyustry`, `#horeca`, `#installyacii`, `#kak-rabotaem`, `#b2b`, `#zayavka`.
- Формы `#quick-form` и `#lead-form` отправляют заявку на `/api/leads`; поля `name` и `contact` переименовывать нельзя.
- Цель Метрики `lead_custom_submitted` (счётчик 110458266) — на неё настроена реклама.
- Файлы `index.html` и `raboty.html` должны оставаться в этой папке: без них сервер обновление не примет и оставит прежнюю версию сайта.

## Как это устроено на сервере

Таймер `satori-promo-sync` на сервере каждые две минуты скачивает ветку `main` и копирует папку `promo/`
в `/var/www/satori/promo/`. Править файлы прямо на сервере бессмысленно: следующая синхронизация их перезапишет.
