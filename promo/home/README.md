# SATORI HOME · /home

Это отдельная промо-страница Satori Home на текущем домене Satori Studio.

- Публичный адрес: https://satorilabural.ru/home
- Исходная HTML-страница: `promo/home/index.html`, автономная (CSS/JS встроены).
- На текущем статическом хостинге маршрут `/home` попадает в fallback `promo/index.html`. Там стоит **точечный загрузчик только для /home**: он получает /promo/home/index.html и заменяет документ, не изменяя публичный URL. Остальные страницы Studio не затронуты.
- Этот способ промежуточный. После доступа к конфигурации Nginx лучше назначить отдельный `location = /home`, отдающий `/var/www/satori/promo/home/index.html` напрямую (без браузерного загрузчика). Тогда у поисковых систем будет полноценный серверный HTML.
- **Пока режим демонстрационный**: без отдельного backend и PR CRM #98 кнопка расчёта скачивает заявку локально, не отправляет персональные данные на сервер. Не сообщайте клиентам, что заявки принимаются.
- Сайт содержит ссылку на действующий Telegram студии как временный канал связи.
- Для боевых заказов требуется подключить backend и единую CRM, опубликовать подходящие юридические документы и проверить защиту данных.
- До открытия боевого приёма заказов проверьте актуальность описания услуг и наличие логистических партнёров.

## Проверка
1. Открыть `/home`: заголовок и макет SATORI HOME, URL остаётся `/home`.
2. Открыть `/`: исходный Satori Studio без изменений.
3. Убедиться, что форма явно в деморежиме и не утверждает, что заявление принято CRM.
4. Проверить `/promo/home/index.html` как запасной адрес и на мобильном устройстве.
