# Satori AI Sales Manager

AI-менеджер работает поверх истории парсера и существующих WhatsApp / Telegram интеграций CRM.

## Что он делает

1. Забирает новые контакты из `crm/data/parser-history.json`.
2. Оценивает релевантность и готовит персонализированный первый контакт.
3. Отслеживает ответы из `crm/data/communications.json`.
4. Квалифицирует лида и хранит краткое резюме диалога.
5. Делает follow-up с лимитом касаний.
6. Останавливается после отказа / просьбы не писать.
7. Передаёт нестандартные случаи человеку.
8. При явном коммерческом интересе создаёт клиента и сделку в общей CRM на этапе «Расчёт».

Рабочее состояние AI хранится в `crm/data/ai-sales.json`. Папка `crm/data/` уже исключена из Git.

## OpenAI

Добавить в корневой `.env` сервера:

```env
OPENAI_API_KEY=...
AI_MANAGER_MODEL=gpt-5.6-luna
```

В OpenAI отправляется только контекст, нужный для продажи: имя, роль, компания, источник и текст диалога. Телефон и email в запрос модели не включаются. Запросы выполняются с `store: false`.

## Режим работы

В интерфейсе CRM → «AI менеджер» есть два переключателя:

- **Менеджер** — анализировать контакты, ответы и готовить следующие действия.
- **Автоотправка** — отправлять сообщения автоматически там, где канал технически позволяет это сделать.

По умолчанию оба переключателя выключены.

## Ограничения и расписание

Можно настроить:

```env
AI_MANAGER_TIMEZONE=Europe/Moscow
AI_MANAGER_START_HOUR=10
AI_MANAGER_END_HOUR=19
AI_MANAGER_DAILY_LIMIT=20
AI_MANAGER_MAX_TOUCHES=3
AI_MANAGER_POLL_MS=20000
```

Менеджер не отправляет сообщения вне рабочего окна, не превышает дневной лимит и после максимального числа касаний передаёт контакт человеку.

## WhatsApp

Обычный WhatsApp text используется для ответов в уже открытом диалоге. Для автоматического холодного первого контакта нужен одобренный Meta template:

```env
WHATSAPP_OUTREACH_TEMPLATE_NAME=satori_intro
WHATSAPP_FOLLOWUP_TEMPLATE_NAME=satori_followup
WHATSAPP_TEMPLATE_LANGUAGE=ru
```

Если template не задан, AI всё равно подготовит персонализированный текст, но первый контакт останется в очереди «Черновик готов» и его можно открыть вручную через WhatsApp.

Текущая реализация передаёт в body parameters template имя и компанию, если они есть. Шаблон Meta должен быть согласован с таким количеством переменных или не использовать переменные.

## Telegram

Telegram Bot API не начинает личный диалог только по `@username`. Поэтому первый контакт по username открывается вручную. Как только человек напишет боту и CRM получит numeric `chat_id`, AI может отвечать автоматически через Bot API.

## Стоп-правила

AI прекращает коммуникацию при явном отказе и фразах типа «не пишите», «не интересно», `stop`, `unsubscribe`. Точные цены, скидки, юридические обещания, конфликты и инженерные гарантии автоматически передаются человеку.

## Данные и сделка

После квалификации AI создаёт обычного клиента в `crm.json` (если его ещё нет) и обычную сделку с `source: ai-parser`. Повторное создание той же сделки блокируется по `sourceAiId`.
